# 产品：Compare View

英文版本：[PRODUCT.md](PRODUCT.md)。

## 目标

在不修改数据表的情况下比较当前飞书多维表格中的记录。传统多维表格将记录映射为行、字段映射为列；Compare View 则将字段垂直呈现，并将已保存的记录水平呈现。

## 行为

- 候选来源是当前数据表的全部记录。当前视图中的可见记录顺序优先，其余记录再按主字段顺序排列。
- 字段选择器和比较矩阵行均按表格级默认字段顺序排列；当前视图不会重排 Compare View 中的字段。
- 全部控件集中在一条工具条上：记录、字段、筛选、分组、排序、行高，保存状态与保存操作位于工具条右端。
- 在「记录」下拉浮层中的同一个候选列表里选择 1–10 条记录，浮层还提供搜索框和清空操作。每条已选行的复选框前都有拖动把手；拖动会改变已保存比较中的顺序，界面有意不再展示独立的已选记录列表。
- 工具条下方的统计条显示比较记录数、可见字段数和存在差异的字段数，并提供「仅看差异」开关，用于隐藏各记录取值完全相同的字段。
- 若某字段在各记录上的取值并不完全相同，其行首会显示彩色标记，单元格文本也会加重。
- 行高提供四档密度。网格文本始终单行显示；超出单元格宽度的值会显示行内展开操作，在只读弹层中查看完整内容。
- 记录列标题可拖动调整顺序，也可通过关闭操作移出比较。两者都只修改草稿，因此该列会保留并标记为待生效，直到保存。
- 字段列宽度可通过拖动或方向键调整。
- 默认显示所有非主字段。表格级字段列表中的第一个字段是主字段回退，用作记录列标题，也可以作为普通矩阵行重新显示。
- 筛选、排序、分组和字段显示均是插件内的本地控制，不会修改多维表格原生的筛选、分组、排序或视图设置。
- 针对选择类字段的筛选在复选框列表中选取选项，且可以选中多个；记录需要对每个选中的选项都满足该条件才算匹配。
- 筛选会将记录从选择器候选中移除，但绝不会移除已保存的比较记录。修改排序规则会将所选记录重置为新的排序顺序，之后仍可通过拖动进行手动调整。
- 分组时，一条记录只进入其第一个规范化值对应的分组，因此多值字段不会复制比较列。候选区和矩阵的分组均可在本地折叠，折叠状态不保存。
- 空值显示为 `—`。矩阵优先使用 SDK 格式化显示文本，并会对复杂单元格安全降级。

## 保存与共享

所有会影响结果的控制均为草稿。只有点击**保存**才会更新比较矩阵；**放弃修改**会恢复上一次保存的配置，**重置**会准备默认值，等待后续保存。

已保存配置包含所选记录 ID、隐藏字段 ID、筛选规则、排序规则和分组字段，并通过飞书官方 Bridge 数据存储共享。拥有 Base 编辑权限的用户可保存；只读用户可以加载最后一次保存的配置。并发保存采用最后一次成功写入生效的行为。

中英文选择、飞书外观、分组折叠状态、行高、「仅看差异」开关和字段列宽度仅保留在当前会话中。

## 非目标

Compare View 不编辑单元格、不写入多维表格业务数据、不修改原生多维表格视图设置、不添加后端或数据库、不实现身份验证或自动化，也不发布插件包。唯一允许的 SDK 可变操作是 Bridge 配置存储，它不属于多维表格数据写入。

差异标记只比较各记录格式化后的显示文本，并仅判断字段取值是否完全相同。它不是语义或数值差异比较：不计算差值、不标注字符级范围，也不做区分字段类型的比较。
