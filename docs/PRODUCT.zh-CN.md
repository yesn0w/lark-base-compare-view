# 产品：Compare View

英文版本：[PRODUCT.md](PRODUCT.md)。

## 目标

在不修改数据表的情况下比较当前飞书多维表格视图中的多条记录。传统多维表格将记录映射为行、字段映射为列；Compare View 则将字段垂直呈现，并将选中的记录水平呈现。

## MVP 行为

- 在 SDK 可用时读取当前数据表和当前视图。
- 列出该视图中可见的记录，并允许用户选择 1–10 条。
- 选中至少一条记录后立即展示字段矩阵。
- 因为已安装 SDK 未公开明确的主字段标记，所以使用第一条有序字段作为主字段显示回退。
- 默认显示所有非主字段；用户可显示主字段或隐藏其他任意字段。
- 使用无障碍箭头控件重新排序选中的记录。
- 将空单元格显示为 `—`，保留固定字段名称列，并支持横向滚动。
- 提供仅在当前会话有效的中英文语言选择器。
- 跟随当前飞书浅色/深色外观；宿主外观变化时同步更新，且不持久化本地偏好。

## 非目标

MVP 不编辑单元格、不写入 Base 数据、不持久化比较设置、不添加后端或数据库、不实现身份验证或自动化，也不计算字段差异。
