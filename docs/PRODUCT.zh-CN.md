# 产品：Compare View

英文版本：[PRODUCT.md](PRODUCT.md)。

## 目标

在不修改数据表的情况下比较当前飞书多维表格中的记录。传统多维表格将记录映射为行、字段映射为列；Compare View 则将字段垂直呈现，并将已保存的记录水平呈现。

## 行为

- 候选来源是当前数据表的全部记录。当前视图中的可见记录顺序优先，其余记录再按主字段顺序排列。
- 默认字段顺序沿用适配器：SDK 识别出的主字段在前，其余字段保留元数据顺序。字段浮层可为显示和隐藏字段统一暂存不同顺序。
- 全部控件集中在一条工具条上：记录、字段、筛选、分组、排序、行高，保存状态与保存操作位于工具条右端。
- 在「记录」下拉浮层中的同一个候选列表里选择一条或多条记录，插件不设数量上限，浮层还提供搜索框和清空操作。勾选或取消勾选不改变候选位置；新勾选的记录追加到对比顺序末尾，取消后重选也追加到末尾。手动拖动排序仅在对比表头提供，保存后生效。
- 工具条下方的统计条显示比较记录数、可见字段数和存在差异的字段数，并提供「仅看差异」开关，用于隐藏各记录取值完全相同的字段。
- 若某字段在各记录上的取值并不完全相同，其行首会显示彩色标记，单元格文本也会加重。
- 行高提供四档最小高度。每个字段可独立换行，包含字段名、标签和附件文件名；保留原有换行符，长字符串在现有列宽内断行，行高随内容增长。附件文件名换行独立于固定图片区域。
- 未换行的非附件文本超过 36 字符或包含换行符时提供「展开」，立即展开整个字段行；字段名旁「收起」恢复已保存的换行设置。多行可同时展开，手机和只读用户也能使用。
- 附件单元格以 240px 高的区域等比完整显示当前图片，不受行高影响。上一张/下一张按源顺序切换，首尾禁用，与只读预览同步；缺少地址或加载失败的图片保留位置并显示文件名，其他文件列于下方。仅挂载当前图片并懒加载，不预加载图库。
- 记录列标题可拖动调整顺序，也可通过关闭操作移出比较。两者都只修改草稿，因此该列会保留并标记为待生效，直到保存。
- 所有列独立调宽：字段列默认 200px、范围 140–420px；记录列默认 220px、范围 160–800px。宽度按记录 ID 保留，排序、分组或取消重选不丢失。表格实际宽度为各列之和，支持横向滚动。拖动预览、松手共享，Escape/取消恢复本次操作；方向键每次 16px，停止 300ms 或失焦后共享；双击或 Home 恢复该列默认值。手机和只读用户不能调宽。
- 默认显示所有非主字段。SDK 识别出的主字段用作记录列标题，也可以作为普通矩阵行重新显示。
- 筛选、排序、分组和字段显示均是插件内的本地控制，不会修改多维表格原生的筛选、分组、排序或视图设置。
- 针对选择类字段的筛选在复选框列表中选取选项，且可以选中多个；记录需要对每个选中的选项都满足该条件才算匹配。
- 筛选会将记录从选择器候选中移除，但绝不会移除已保存的比较记录。修改排序规则会将所选记录重置为新的排序顺序，之后仍可通过拖动进行手动调整。
- 分组时，一条记录只进入其第一个规范化值对应的分组，因此多值字段不会复制比较列。候选区和矩阵的分组均可在本地折叠，折叠状态不保存。
- 单元格按每批最多 12 个任务渐进加载；未返回的值显示「加载中…」，未全部加载的字段暂不计入差异，也不会被「仅看差异」隐藏，加载完成后才参与判断。单格读取失败沿用空值降级，不清空其他单元格。
- 空值显示为 `—`。矩阵优先使用 SDK 格式化显示文本，并会对复杂单元格安全降级。

## 保存与共享

记录、查询和字段设置先保留为草稿。点击**保存**后才将这些设置应用到比较矩阵；**放弃修改**会恢复上一次保存的配置，**重置**会准备默认值，等待后续保存。

已保存配置包含所选记录 ID、隐藏字段 ID、筛选规则、排序规则、分组字段、字段顺序、换行字段 ID 和列宽，并通过飞书官方 Bridge 数据存储共享。拥有 Base 编辑权限的用户可保存；只读用户可以加载最后一次保存的配置。飞书手机 App 同样加载该配置，但所有影响结果的控件均保持只读；视图创建和配置修改在网页端或桌面客户端完成。并发保存采用最后一次成功写入生效的行为。允许保存空选择，此时显示选择引导。配置保持版本 1，无需迁移。插件不设记录数量上限；宿主拒绝保存时保留草稿和上次成功保存的比较结果。旧插件版本读取时仍会截断已选记录，因此跨标签页验收应全部使用更新后的版本。

中英文选择、飞书外观、分组折叠状态、行高、「仅看差异」开关、临时行展开和附件图片位置仅保留在当前会话中。

附件缩略图 URL 是临时呈现数据，只保存在内存中，随 Base 数据刷新，并且绝不会进入已保存的 Bridge 配置。

## 非目标

Compare View 不编辑单元格、不写入多维表格业务数据、不修改原生多维表格视图设置、不添加后端或数据库、不实现身份验证或自动化、不下载或上传附件，也不发布插件包。唯一允许的 SDK 可变操作是 Bridge 配置存储，它不属于多维表格数据写入。

从飞书手机 App 新建 Compare View 也不属于插件运行时能力。宿主必须先创建并绑定自定义视图，本 React 应用才会加载，因此手机用户需要打开此前在网页端或桌面客户端创建的视图。

差异标记只比较各记录格式化后的显示文本，并仅判断字段取值是否完全相同。它不是语义或数值差异比较：不计算差值、不标注字符级范围，也不做区分字段类型的比较。

## 字段展示控制

字段浮层每项包含拖动把手、显示复选框、字段名和换行开关。隐藏字段保留在同一排序列表中，保留换行设置，重新显示时回到原位置。把手拖动支持首尾插入和边缘滚动；Alt＋上/下方向键可移动并播报位置。「全部显示/隐藏」只改变显隐，「恢复默认顺序」只改变顺序。这些操作需要编辑权限，保存中禁用；放弃修改和保存失败保留最后成功保存的矩阵。

临时展开在排序、分组、仅看差异和无关保存后保留。保存为隐藏或删除字段时清除对应展开状态；切换数据源、刷新数据或整页刷新清空全部临时展开。关闭已保存的换行后，临时展开的行需点击「收起」才恢复单行。

## 列宽与图片浏览

列宽是即时生效并自动共享的例外，其他设置仍为草稿。共享有独立状态；失败保留本地布局并提供重试和恢复已共享列宽，放弃修改只作用于其他草稿。普通保存先等待列宽共享，失败则停止。存在待共享列宽时，刷新/数据源变更提示处理；整页离开使用浏览器的未保存警告。

版本 1 新增 `fieldColumnWidth: number | null`（默认 `null`）和 `recordColumnWidths: Record<string, number>`（默认 `{}`）。有限数值取整并限制范围，无效值和已删除记录 ID 清理；仍存在但未选中的记录保留宽度。对象键顺序不作为设置差异。旧版本保存可能丢弃新增设置，测试标签页统一使用新版。

图片位置在当前数据源会话内临时保留。排序、分组折叠、仅看差异及无关保存保留位置；保存隐藏/移除、附件变化、数据源变化和主动刷新清理相关位置。图片及 URL 不进入共享配置。调宽和切图不改变单元格加载 key，也不增加读取。

折叠分组在矩阵上方提供展开入口，全部分组折叠时仍可恢复；此阅读操作保留列宽和图片位置。
