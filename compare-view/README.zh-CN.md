# Compare View 插件

英文版本：[README.md](README.md)。

此目录是基于飞书官方 React + TypeScript + Webpack 模板生成的数据表视图插件。

请参阅根目录 [README](../README.zh-CN.md) 了解安装、本地配置、验证和发布边界。`block.json` 有意仅保留在本地且已被 Git 忽略；启动开发服务器前请先复制 `block.json.example`。

字段显隐、顺序和换行属于保存后共享生效的设置；行内展开只在当前会话临时生效。运行 `npm test` 检查字段控制及既有记录、手机、附件和分批加载回归。
