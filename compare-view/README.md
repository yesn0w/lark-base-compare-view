# Compare View extension

Chinese version: [README.zh-CN.md](README.zh-CN.md).

This directory is the Feishu Data Table View Extension generated from the
official React + TypeScript + Webpack template.

Use the root [README](../README.md) for setup, local configuration, validation,
and release boundaries. `block.json` is intentionally local and ignored by Git;
copy `block.json.example` before starting the development server.

Field visibility, order, and wrapping are shared save-to-apply settings. Inline
row expansion is temporary. Run `npm test` for field controls and the existing
record, mobile, attachment, and batched-loading regressions.

Column widths preview immediately and share automatically without submitting other drafts; failed shares offer retry/restore. Attachments show a 240px-high current image with inline navigation synchronized with preview. Run `npm test` for column-width coordination and attachment-carousel regressions.
